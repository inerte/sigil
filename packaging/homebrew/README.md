# Homebrew Packaging

This directory keeps the canonical Homebrew formula snapshot for Sigil and the checksum input used to generate it.

- `Formula/sigil.rb` is generated by `projects/homebrewPackaging`
- `SHA256SUMS` is the current release checksum snapshot used for local verification
- the generated formula installs the bundled `language/` and `runtime/` payloads under `share/sigil/`
- the generated formula declares `node` as a runtime dependency for `sigil run`, `sigil test`, `sigil validate`, `sigil inspect world`, and `sigil debug ...`

## Local generation

```bash
pnpm sigil:package:homebrew
```

## CI verification

```bash
pnpm sigil:test:homebrew
```

## Tap publishing

GitHub release archives are authoritative. A separate release-triggered
Homebrew workflow downloads those assets, verifies `SHA256SUMS`, generates the
formula with the released binary, installs and tests the formula, and only then
pushes `inerte/homebrew-tap` when `HOMEBREW_TAP_DEPLOY_KEY` is configured.

The workflow supports a manual version retry and refuses to replace a newer tap
formula with an older release. The tap repo should contain `Formula/sigil.rb`
and no generation logic.
